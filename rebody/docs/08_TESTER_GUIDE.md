# 테스터 안내문 (R3-3)

**아래 §2를 그대로 복사해서 테스터에게 보내세요.** 카카오톡·문자 어디든 붙여넣으면 됩니다.

---

## 1. 운영자용 — 이 구간에서 실패하는 이유는 거의 정해져 있습니다

Google은 **12명 이상이 14일 연속으로 opt-in한 상태**를 요구합니다. (20명이 아닙니다 —
2024-12-11에 완화됐습니다.) 그런데 대부분의 1인 개발자가 여기서 한 번 실패하고 다시 시작합니다.
원인은 셋뿐입니다.

| 실패 원인 | 대응 |
|---|---|
| 초대만 보내고 설치를 확인하지 않음 | **초대 수락 + 실제 설치**까지가 opt-in입니다. 설치 스크린샷을 회신받으세요 |
| 중간에 앱을 지운 사람이 생김 | 12명이 같은 14일 창에 겹쳐야 합니다. **15~16명** 모집으로 버퍼를 두세요 |
| 초대 이메일과 로그인 계정이 다름 | Play에 등록한 Gmail로 **로그인한 상태**여야 인식됩니다. 이 점을 미리 알려주세요 |

체크 방법: Play Console → 테스트 → 비공개 테스트 → **opt-in 인원 수**를 매일 확인.
숫자가 12 미만으로 떨어진 날이 있으면 그날부터 다시 셉니다.

**14일 동안 네이티브 재빌드를 하지 마세요.** 재설치를 유발하고, 1명이 이탈하면 2주가 리셋됩니다.
버그 수정은 `eas update`(OTA)로만 배포하세요 — 사용자가 앱을 다시 켜면 자동 적용됩니다.

### 모집할 때 솔직하게 말할 것

"테스트해 줘"보다 "**2주 동안 앱을 지우지 말고 하루 한 번만 열어줘**"가 정확한 요청입니다.
Google 규칙 때문에 필요하다는 사실을 그대로 알리는 편이 협조를 얻기 쉽습니다.

## 2. 테스터에게 보낼 안내문 (여기부터 복사)

```
안녕하세요! 만들고 있는 앱 테스트를 도와주실 수 있을까 해서 연락드렸어요.

■ 앱 소개
ReBody — 간헐적 단식(공복 시간) 스케줄을 내 생활 패턴에 맞춰 잡아주는 앱이에요.
직장인, 학생, 알바, 교대근무, 해외출장처럼 하루 리듬이 다른 사람도 쓸 수 있게 만들었어요.
무료이고 광고도 결제도 없습니다.

■ 부탁드리는 것 (딱 두 가지)
1. 아래 링크로 설치해 주세요 — Play 스토어 등록에 쓰는 Gmail 계정으로 로그인된 상태여야 해요.
2. 2주 동안 앱을 지우지 말고, 하루에 한 번만 열어봐 주세요.

   Google 정책상 "12명이 14일 연속으로 설치를 유지"해야 정식 출시 신청이 가능해요.
   중간에 한 분이라도 지우면 처음부터 다시 세야 해서, 이 부분만 꼭 부탁드립니다.

■ 설치 링크
(Play Console 비공개 테스트 링크를 여기에 붙여주세요)

■ 설치 후 한 번 해보시면 좋은 것
· 가입 → 동의 화면 → 키·몸무게 입력 → 생활 패턴 선택 (2분 정도)
· 홈 화면의 큰 타이머 확인 (지금 먹어도 되는지 알려줘요)
· 음식 사진 한 장 찍어서 기록해보기 (하루 3회까지)
· 알림이 오면 눌러보기

■ 이런 게 있으면 알려주세요
· 앱이 갑자기 닫히거나 화면이 하얗게 되는 경우 → 그때 뭘 하고 있었는지
· 시간이 이상하게 표시되는 경우 (특히 야간 근무나 새벽 시간대)
· 문구가 이해되지 않거나 어색한 부분
· "이건 왜 안 되지?" 싶었던 순간

캡처 한 장이면 충분해요. 완벽한 버그 리포트는 필요 없습니다.

■ 개인정보
키·몸무게·식사 기록은 국내 서버에 저장되고, 앱에서 계정 삭제를 누르면 사진까지 즉시 지워져요.
테스트가 끝난 뒤 계정 삭제를 원하시면 언제든 말씀해 주세요.

감사합니다!
```

## 3. 운영자 일일 체크 (14일)

매일 1분이면 됩니다.

- [ ] Play Console → 비공개 테스트 → opt-in 인원 **12명 이상 유지** 확인
- [ ] Crashlytics 새 크래시 확인 (있으면 OTA로 당일 수정)
- [ ] Supabase → `select pinged_at from system_heartbeat;` — 무료 티어 슬립 방지 동작 확인
- [ ] `select * from ai_usage_recent limit 3;` — AI 예산 소진 속도 확인 (상한 2,000건/일)
- [ ] 테스터 회신 확인 → 치명적인 것만 즉시, 나머지는 목록화

### 이탈자가 생겼을 때

1. 조용히 대체 인원 1명을 추가 모집 (버퍼 인원을 미리 확보해 두는 이유)
2. Play Console에서 opt-in 수치가 12 미만으로 내려간 날짜를 기록
3. **그날 이후로 14일을 다시 셉니다.** 이전 기간은 사라집니다

## 4. 테스터에게 보상할 것이 없다는 문제

무료 앱이고 수익도 없어서 금전 보상을 할 수 없습니다. 현실적인 대안:

- **결과를 공유하기** — 2주 뒤 "덕분에 출시 신청까지 갔다"는 보고. 참여감이 실제로 작동합니다
- 크레딧에 이름 남기기 (동의받은 경우만)
- 요청 범위를 최소로 유지 — "하루 한 번 열기"는 지킬 수 있는 부탁입니다.
  "매일 식사를 기록해 달라"는 지켜지지 않고, 안 지켜지면 미안해서 앱을 지웁니다

지인 12명이 부담스러우면 개발자 커뮤니티의 상호 테스트 그룹(서로 테스터가 되어주는 모임)을
찾는 방법도 있습니다. 다만 실사용 피드백의 질은 낮으므로, 절반은 실제 타겟 사용자로
채우는 편이 낫습니다.
