## 비용 최소화 장치 (코드에 구현된 것)

1. **영양정보 캐시** — `food_nutrition_cache`. 동일 음식 재스캔 시 MFDS/Gemini 호출 생략. 히트율이 곧 비용 절감률.
2. **서버측 스캔 쿼터** — `consume_scan_quota()`. 무료 3회/일을 DB에서 원자적으로 강제. 클라이언트 우회 불가.
3. **출력 토큰 상한 + structured output** — 모든 호출에 `maxOutputTokens` + `responseSchema`. 장문 서술 차단.
4. **집계 후 전송** — 주간 피드백은 원본 로그가 아니라 집계 통계만 전송. 토큰·프라이버시 동시 절감.
5. **모델 ID 환경변수화** — `GEMINI_MODEL`. 단가 변동/모델 종료 시 재배포 없이 교체.
6. **OTA 우선 배포** — JS/UI 변경은 `eas update`, 네이티브 변경 시에만 `eas build`.
7. **keepalive cron** — Supabase 무료 프로젝트 일시정지 방지 (정지되면 복구에 시간 소모 = 간접 비용).
