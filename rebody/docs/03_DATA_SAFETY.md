# Play Console — Data Safety 신고 초안 (ReBody)

> 이 문서는 Play Console의 "데이터 보안" 섹션에 그대로 옮겨 적기 위한 초안입니다.
> **신고 내용과 실제 앱 동작이 어긋나면 정책 위반입니다.** 코드를 바꿀 때마다 이 문서를 함께 갱신하세요.
>
> 검증 방법: `src/lib/analytics.ts`의 이벤트 파라미터, `supabase/functions/*`가 외부로 보내는 필드,
> `supabase/migrations/*`의 컬럼을 대조합니다.

## 2. 보안 관행 신고

- **전송 중 암호화**: 예. 모든 통신은 HTTPS/TLS.
- **삭제 요청 경로 제공**: 예. 앱 내 `설정 > 계정 삭제`
  (`delete_my_account()` — auth.users 삭제 시 cascade로 전 데이터 및 Storage 객체 제거).
- **Play Families 정책 대상**: 아니오. 만 18세 이상 대상.
- **독립 보안 심사**: 아니오.
- **광고 포함**: 아니오. 광고 SDK를 넣지 않았습니다.
- **인앱 구매**: 아니오. 결제 코드가 `MONETIZATION_ENABLED = false`로 잠겨 있고
  구독 상품을 등록하지 않습니다 (`07_MONETIZATION_DEFERRED.md`).
- **광고 목적 데이터 사용**: 아니오. 건강 데이터는 물론 어떤 데이터도 광고에 쓰지 않습니다.

## 3. 제3자 공유 상세 (심사 문의 시 답변용)

### 3-1. Google Gemini API
- **전송 데이터**: 식사 사진(임시), 음식명, 주간 집계 통계, 근무 스케줄 텍스트
- **전송하지 않는 데이터**: 이메일, 사용자 ID, 이름, 개별 로그 원본
- **목적**: 음식 인식 및 코칭 문구 생성
- **보관**: 앱은 Gemini에 사진을 보관하지 않음. 요청 단위로 전송 후 즉시 폐기
- **설계 근거**: 주간 피드백은 원본 로그가 아니라 `get_weekly_stats()`의 **집계값만** 전송합니다
  (`supabase/functions/generate-weekly-feedback/index.ts`). 국외 이전되는 개인정보 범위를 구조적으로 줄인 것입니다.

### 3-2. Google Firebase (Analytics / Crashlytics / FCM)
- **전송 데이터**: 익명 이벤트명, 화면 이름, 크래시 스택, FCM 토큰
- **전송하지 않는 데이터**: 건강 데이터, 칼로리, 식사 내용, 사진
- **검증**: `src/lib/analytics.ts` 상단 주석 — 이벤트 파라미터에 개인 식별정보·건강 데이터 금지

### 3-3. Supabase (데이터 저장)
- 데이터 처리 위탁사이며 "제3자 공유"가 아닌 "처리 위탁"으로 신고합니다.
- 리전: `ap-northeast-2` (서울). 국내 저장.

### 3-4. 식약처 공공데이터포털
- 전송: 음식명 문자열만 (조회 쿼리)
- 개인정보 미전송

## 4. 국내 규제 대응 (Play Console 항목 밖이지만 필수)

### 4-1. 민감정보 별도 동의 — 개인정보보호법 제23조
건강 정보(단식·식사·체중)는 민감정보입니다. 일반 개인정보 동의와 **분리된 별도 체크박스**가 필요합니다.
→ 구현: `consents` 테이블 (`kind = 'sensitive_health_data'`), 온보딩 동의 화면에서 개별 수집.

### 4-2. 국외이전 별도 동의 — 제28조의8
Gemini API는 미국 소재 서버로 데이터를 전송합니다. 별도 동의가 또 필요합니다.
→ 구현: `consents.kind = 'overseas_transfer'`.
→ 고지 항목: 이전받는 자(Google LLC), 이전 국가(미국), 이전 항목(사진·음식명·집계 통계), 이전 목적, 보유 기간.

### 4-3. 동의 이력 보관
`consents`는 append-only입니다 (update/delete RLS 정책 없음). 철회는 `granted=false` 행을 추가합니다.
정책 문구를 개정하면 `POLICY_VERSION`(`src/store/useAuthStore.ts`)을 올리고 재동의를 받습니다.

## 5. 건강 앱 추가 선언

Google Play는 건강 관련 앱에 별도 선언을 요구합니다.

- **의료기기 아님**: ReBody는 진단·치료·예방 목적의 의료기기가 아닙니다.
- **면책 고지 노출 위치**: 온보딩, 대시보드 하단 상시 노출 (`MEDICAL_DISCLAIMER`, `src/domain/safety.ts`)
- **안전장치**:
  - 만 18세 미만 단식 기능 차단
  - BMI < 18.5 단식 기능 차단
  - 임신·수유 중 차단
  - 섭식장애 병력 자가 신고 시 차단
  - 단식 목표 24시간 하드 캡 (DB 제약 `fasting_target_max_24h` + 클라이언트 `clampFastingHours`)
  - AI 코칭 프롬프트에 "칼로리 추가 제한·단식 연장·감량 가속 권유 금지" 하드 제약
