## 3. 자세한 설명 (4000자 이내)

```
매일 같은 시간에 일어나지 않아도 간헐적 단식을 할 수 있습니다.

시중의 단식 앱은 대부분 "아침 8시에 첫 끼, 저녁 4시에 마지막 끼"처럼 고정된 하루를 전제합니다.
하지만 현실은 그렇지 않습니다. 요일마다 수업 시간이 다른 학생, 주에 두세 번 저녁 알바를 하는 사람,
정해진 출근 시간이 없는 은퇴·재택 근무자, 시차가 바뀌는 출장자, 그리고 2·3교대 근무자에게
"매일 같은 시각"은 성립하지 않습니다.

ReBody는 순서를 뒤집습니다. 먼저 당신의 하루가 어떻게 반복되는지(사이클)를 이해하고,
그 위에 식사 창을 배치합니다.


■ 내 하루를 고르면 끝

9가지 생활 패턴 중에서 고르세요. 질문은 하나뿐입니다.

· 매일 같은 리듬 — "보통 몇 시에 일어나세요?"
· 주간 직장인 — 평일 출근, 주말 휴식
· 학생·수험생 — 수업과 야간 자습을 고려한 배치
· 알바·프리랜서 — 요일마다 다른 일정
· 은퇴·재택 — 출퇴근 기준점이 없어도 괜찮습니다
· 야간 고정 / 2교대 / 3교대 — 며칠 단위로 도는 로테이션
· 출장·시차 적응 — 도착하면 시간대만 바꾸면 됩니다

정확히 맞지 않아도 됩니다. "수요일은 오후 2시부터 알바예요" 같은 한 문장으로 고칠 수 있습니다.


■ 지금 먹어도 되는지, 한 화면에서

앱을 열면 가장 먼저 보이는 것은 큰 숫자 하나입니다. 단식 중이면 남은 시간,
식사 가능하면 창이 닫히기까지 남은 시간. 1초마다 갱신됩니다.
"내가 지금 어디쯤인가"를 생각할 필요가 없습니다.


■ 사진 한 장으로 식사 기록

먹은 음식을 찍으면 음식 이름과 영양성분을 추정합니다.
식품의약품안전처 공공 영양 데이터베이스를 먼저 조회하고, 공식 데이터가 있으면 그 값을 씁니다.
공식 데이터인지 AI 추정치인지 화면에 표시하므로, 어떤 근거의 숫자인지 알 수 있습니다.
중량을 조절하면 영양소가 비례해서 다시 계산됩니다.

사진 분석은 하루 3회까지 이용할 수 있습니다. 이 앱은 광고도 유료 플랜도 없어서
외부 AI 호출 비용을 개발자가 직접 부담하고 있기 때문입니다. 한도를 넘으면
음식 이름을 직접 입력해 기록하실 수 있고, 자정이 지나면 다시 채워집니다.


■ 주간 리포트와 1탭 조정

일주일치 기록이 모이면 패턴을 정리해 알려드립니다.
"식사 창을 30분 늦추는 편이 낫겠어요" 같은 제안이 있으면 한 번 눌러 바로 스케줄에 반영됩니다.
읽고 넘기는 조언이 아니라 실제로 다음 주가 달라집니다.


■ 캘린더로 내보내기

단식·식사 시간을 .ics 파일로 내보내 구글 캘린더나 다른 캘린더 앱에서 볼 수 있습니다.


■ 알림은 필요한 것만

단식 시작·종료 알림, 기록 리마인더, 소식 알림을 각각 따로 켜고 끌 수 있습니다.
Android 설정에서도 세 종류가 분리되어 표시됩니다.


■ 안전을 먼저 확인합니다

간헐적 단식이 모든 사람에게 적합한 방법은 아닙니다.
그래서 시작 전에 몇 가지를 확인하고, 아래에 해당하면 단식 스케줄 기능을 제공하지 않습니다.

· 만 18세 미만
· BMI 18.5 미만 (저체중)
· 임신 중 또는 수유 중
· 섭식장애 병력

이 경우에도 앱을 쓸 수 없게 만들지는 않습니다. 식사 기록과 영양 분석은 그대로 이용하실 수 있습니다.
혈당 관련 약을 복용 중이라고 알려주시면, 시작 전에 의료진과 상의하도록 안내드립니다.


■ 이 앱이 하지 않는 것

· 광고를 보여주지 않습니다
· 유료 플랜이나 인앱 결제가 없습니다
· 건강 데이터를 광고 목적으로 사용하지 않습니다
· 계정 삭제를 요청하면 기록과 사진까지 즉시 삭제합니다


■ 데이터 처리

건강 기록은 「개인정보 보호법」상 민감정보입니다. 그래서 이용약관 동의와 분리해서
별도로 동의를 받고, 국내(서울) 서버에 저장합니다. 음식 사진 분석과 문장 해석에는
Google의 AI를 사용하며, 이 국외 이전에 대해서도 따로 동의를 받습니다.
동의하지 않으셔도 나머지 기능은 이용하실 수 있습니다.


■ 참고해 주세요

ReBody가 제공하는 정보는 일반적인 건강 정보이며, 의학적 진단이나 처방을 대체하지 않습니다.
지병이 있거나 약을 복용 중이라면 시작 전에 의료진과 상의해 주세요.
영양성분 추정치는 실제 섭취량과 차이가 있을 수 있습니다.
```

→ 2,072자 (4000자 제한 내).

### 심사 반려를 부르는 표현 — 절대 쓰지 말 것

| 금지 | 이유 |
|---|---|
| "치료", "완치", "질병 개선" | 의료기기·의약품 오인 |
| "체중 감량 보장", "○kg 감량" | 효과 보장 주장 |
| "의학적으로 검증된" | 근거 없는 의학 주장 |
| "다이어트 필수 앱" 류 최상급 | 객관적 근거 없는 우위 주장 |

위 본문에는 하나도 쓰지 않았습니다. 수정하실 때 이 표를 다시 확인하세요.

## 4. ASO 키워드 우선순위

Play는 별도 키워드 필드가 없어 **앱 이름 → 짧은 설명 → 자세한 설명 앞부분** 순으로 가중치가 실립니다.
위 문구는 그 순서에 맞춰 배치했습니다.

| 순위 | 키워드 | 배치 위치 |
|---|---|---|
| 1 | 간헐적 단식 | 앱 이름 · 짧은 설명 · 본문 첫 문장 |
| 2 | 16:8 | 짧은 설명 |
| 3 | 단식 타이머 | 본문 "지금 먹어도 되는지" 절 |
| 4 | 공복 시간 | 본문 |
| 5 | 식단 기록 · 칼로리 기록 | 본문 사진 기록 절 |
| 6 | 교대근무 · 야간근무 | 짧은 설명 · 본문 (롱테일. 경쟁이 거의 없어 전환율이 높다) |
| 7 | 시차 · 출장 | 본문 (롱테일) |

**교대근무를 1순위로 올리지 마세요.** 검색량이 작아서 전체 유입을 좁힙니다.
반대로 완전히 빼지도 마세요 — 경쟁이 없어 확실하게 1위를 먹는 키워드입니다.

## 5. Play Console 나머지 필수 항목

| 항목 | 값 |
|---|---|
| 카테고리 | 건강/피트니스 |
| 태그 | 건강 관리, 영양 |
| 콘텐츠 등급 | 전체이용가 (설문에서 의료·건강 정보 제공으로 응답) |
| 타겟 연령 | **18세 이상** — 앱이 만 18세 미만의 단식 기능을 차단하므로 일치시켜야 합니다 |
| 광고 포함 | **아니요** |
| 인앱 구매 | **아니요** |
| 개인정보처리방침 URL | D1-3에서 만든 GitHub Pages URL |
| 앱 액세스 권한 | 로그인 필요 — 심사용 테스트 계정을 제공해야 합니다 |
| 데이터 보안 | `03_DATA_SAFETY.md` 표를 그대로 |

> **앱 액세스 권한**을 빠뜨리면 심사에서 "기능을 확인할 수 없음"으로 반려됩니다.
> 테스트 계정 이메일·비밀번호를 Play Console에 등록하세요. 이 계정은 단식 스케줄이
> 이미 생성된 상태로 두는 것이 좋습니다 — 심사자가 온보딩을 다 통과할 필요가 없어집니다.
