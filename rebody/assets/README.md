# assets — 임시 플레이스홀더

`app.config.ts`가 참조하는 4개 파일이 없으면 `eas build`가 실패하므로,
빌드를 통과시키기 위한 **임시 이미지**를 넣어 두었습니다. 디자인이 아닙니다.

| 파일 | 크기 | 용도 | 교체 시점 |
|---|---|---|---|
| `icon.png` | 1024×1024 | 앱 아이콘 | R4-1 |
| `adaptive-icon.png` | 1024×1024 (투명 배경) | Android 적응형 아이콘 전경 | R4-1 |
| `splash.png` | 1024×1024 | 스플래시 | R4-1 |
| `notification-icon.png` | 96×96 (흰색 실루엣) | 알림 아이콘 | R4-1 |

교체할 때 지킬 것:

- `notification-icon.png`는 **흰색 단색 실루엣 + 투명 배경**이어야 합니다.
  컬러 이미지를 넣으면 Android가 전체를 흰 사각형으로 렌더링합니다.
- `adaptive-icon.png`는 안전 영역(중앙 66%) 안에 로고를 두세요. 바깥은 잘립니다.
- 스토어 등록용 512×512 아이콘과 1024×500 피처 그래픽은 별도입니다 (R4-1, R4-2).
