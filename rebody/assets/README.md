# assets — 브랜드 에셋

전부 `scripts/gen-brand-assets.js`가 생성합니다. 이미지를 직접 편집하지 말고 스크립트를 고치세요 —
색·비율·여백 규칙이 코드로 남아야 크기가 바뀔 때 다시 그릴 필요가 없습니다.

```bash
node scripts/gen-brand-assets.js          # 앱 에셋 4종
node scripts/gen-brand-assets.js --store  # 스토어 에셋까지
```

## 디자인 컨셉 — "진행 중인 링"

단식은 "지금 어디쯤인가"가 전부인 경험입니다. 그래서 마크는 시계도 접시도 아니라
**한 바퀴 도는 링**입니다. 링의 빈 구간(우상단 60°)이 남은 시간, 안쪽 점이 지금 이 순간입니다.
색은 앱의 `eating` 그린(`#4ADE80`) 하나만 씁니다 — 단색이어야 알림 아이콘과
모노크롬 테마에서도 그대로 통합니다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `icon.png` | 1024×1024 | 앱 아이콘 |
| `adaptive-icon.png` | 1024×1024, 투명 | Android 적응형 아이콘 전경 |
| `splash.png` | 1024×1024 | 스플래시 (`resizeMode: contain`) |
| `notification-icon.png` | 96×96, 흰색 실루엣 | 알림 아이콘 |
| `store/icon-512.png` | 512×512 | Play Console 스토어 아이콘 |
| `store/feature-graphic-1024x500.png` | 1024×500 | 피처 그래픽 |

## 지켜야 하는 제약

- **알림 아이콘은 흰색 단색 + 투명 배경.** Android는 알파 채널만 쓰고 색은
  `app.config.ts`의 `color`로 덮습니다. 컬러 이미지를 넣으면 전체가 흰 사각형으로 렌더링됩니다.
- **적응형 아이콘은 중앙 66% 안에.** 바깥은 런처 마스크가 잘라냅니다. 스크립트가 반지름 250으로
  잡아 여백을 확보해 두었습니다.
- **스토어 아이콘은 투명 배경 불가.** Play Console이 반려합니다.
- **피처 그래픽의 우측 절반은 비워 둔 것**입니다. 문구를 얹을 자리입니다 —
  폰트 렌더링은 스크립트 범위 밖이라 Figma에서 얹으세요. 문구 후보는
  `docs/09_STORE_LISTING.md`에 있습니다.
